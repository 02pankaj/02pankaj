## 🧠 Technical Challenges & Solutions

### 1. Real-Time State Management for Exams
**Challenge:** Ensuring the exam timer and question state remained synced even if the user accidentally refreshed the browser.
**Solution:** Implemented **React Context API** combined with **sessionStorage**. This allowed the application to "remember" exactly where the student left off without losing time or progress, providing a seamless "Exam Hall" experience.

### 2. High-Concurrency Leaderboards
**Challenge:** Fetching and sorting thousands of student scores in real-time could potentially slow down the app and increase Firebase costs.
**Solution:** Optimized **Firebase Firestore queries** by using indexed ordering and limiting the initial fetch to the Top 10 ranks. This reduced document reads by 80% while keeping the competition high-speed and responsive.

### 3. Dynamic Performance UI
**Challenge:** Creating a visual feedback system that instantly changes colors (Rose/Emerald/Indigo) based on the student's accuracy.
**Solution:** Built a custom **Tailwind CSS logic layer** that dynamically injects utility classes based on score percentages, giving students instant psychological feedback on their performance.
